# Fieldline

Hunting map. A wide window is the desk you plan a trip on. A phone is the app you take into the field.

## Run it while you change it

Install [Node 22](https://nodejs.org), then in this folder:

```bash
npm install
npm run dev
```

Open http://localhost:8080. Edit a file and the page reloads.

Marks stay in that browser. They do not hop to your phone on their own. Export GPX from the desk and import that file on the phone.

Search a unit number (22, 5BN, unit 12A) to frame that Arizona game management unit. A tap on the map names the unit and who manages the ground. Wind shows the next hours and Arizona shooting light, a half hour either side of sunrise and sunset. Tap the coordinate chip to switch decimal, DMS, and UTM. A selected mark can show today's sunrise and sunset. The weather card includes the barometer, compared with three hours earlier.
